# Structure 

weather.py – Contains weather functions.

test_mock_basics.py – Tests basic mock objects and attributes.

test_return_value.py – Tests multiple mock return values.

test_side_effect_exception.py – Tests mock exceptions using side effects.

test_side_effect_list.py – Tests sequential mock side effects using lists.

# Requirements

Python 3

pytest

# Installation

Install pytest:

pip install pytest

# Running Tests

Run all tests:

pytest -v

Run a specific test file:

pytest test_mock_basics.py -v
