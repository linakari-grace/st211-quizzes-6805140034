#Structure

weather.py, test_weather.py – Weather functions and mocking tests.

payment.py, test_payment.py – Payment processing and dependency injection.

test_return_value.py – Mock return values and side effects.

userService.py – User service example.

notifications.py, test_notifications.py – Email notifications and patching.

date_utils.py, test_date_utils.py – Date utilities and patching.

test_verify_calls.py – Verifying mock calls and arguments.

#Requirements

Python 3

pytest

#Installation

Install pytest:

pip install pytest

#Running Tests

Run all tests:

pytest -v

Run a specific test file:

pytest test_payment.py -v
